Principales Tecnologías Web

Las tecnologías web permiten crear sitios modernos, interactivos y adaptables a diferentes dispositivos.

HTML

HTML es el lenguaje utilizado para crear la estructura y el contenido de las páginas web.

CSS

CSS permite diseñar y mejorar la apariencia visual de los sitios web.

JavaScript

JavaScript permite agregar interacción, dinamismo y funcionalidades a las páginas web.

Responsive Design

El diseño responsive permite que una página se adapte a computadoras, tablets y celulares.
